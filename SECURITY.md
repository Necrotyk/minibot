## Reporting a Vulnerability

We take the security of Minibots seriously. If you discover a vulnerability or potential exploit:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories at <https://github.com/Necrotyk/minibot/security/advisories/new>.
3. Or email the maintainer directly at `security@dystopi.cc`.

Please include:
- A description of the vulnerability and attack vector.
- Reproduction steps or proof-of-concept script.
- Affected modules or versions.

We will acknowledge receipt within 48 hours and work with you to remediate and publish a security patch.
